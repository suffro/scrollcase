# Architecture

## Overview

Scrollcase turns a declarative **scroll** (`scroll.json`) into a **box**: a portable, locked,
self-contained environment for one operating system and accelerator, packed so it runs somewhere
other than where it was built, signed so a consumer can prove what they received, and accompanied by
a dependency licence inventory. What runs inside a box is its **runtime** — `python`, `node`, or
`native`, which starts a compiled binary and carries no interpreter at all.

The substrate is **pixi + conda-pack + conda-forge**, and only that: `pixi` solves a committed
`pixi.lock`, `conda-pack` relocates the resulting prefix, and the tree is extracted into the box's
`venv`. See [`../decisions/one-substrate.md`](../decisions/one-substrate.md).

Scrollcase is **a library as well as a CLI**, and the CLI has thirteen verbs: `init`, `new`, `add`,
`remove`, `edit`, `refresh`, `doctor`, `keygen`, `lock`, `audit`, `build`, `verify`, `run`.

The operational rules — hard rules, naming, boundaries, the commands to run — live in
`AGENTS.md`, and the public reasoning in `docs/concepts/design-decisions.md`. This file describes
the shape of the system; those two are not repeated here.

## Major components

| Where | What it is |
| --- | --- |
| `src/contract/` | The format itself, and the single source of truth for it: the target model and identity rule (`targets.mjs`), the runtime model — layout, execution kinds, argv, self-test (`runtimes.mjs`), the signed-document envelope and namespacing (`documents.mjs`), `payload-digest.mjs`, `src/contract/schema/`, `src/contract/fixtures/`, generated `src/contract/types/`. |
| `src/runtimes/<id>` | The builder-side half of a runtime: launcher repair, dependency reading, authoring templates, the pixi dependency it contributes, and any payload file the runtime needs that nothing declares. `python`, `node`, `native`, plus the shared `launchers.mjs`. |
| `src/build/` | Solving and packing (`pixi.mjs`), toolchain bootstrap (`toolchain.mjs`), archive and filesystem primitives, the lock-derived licence audit, workspace resolution, scroll authoring (`authoring.mjs`), reading and provenance (`scroll.mjs`), asset staging, the build core (`box.mjs`), `verify.mjs`, `audit.mjs`, `project.mjs` (init/doctor), and the parity gate. |
| `src/sign/` | Key generation, local signing, external-signer dispatch, verification. |
| `src/consumer/` | The Node consumer: verify, extract, attach, run. |
| `src/cli.mjs` | Argument parsing and dispatch, and nothing else. |
| `python/` | The `scrollcase-consumer` PyPI package — the same consumer again, with bundled schema copies. |
| `rust/` | The `scrollcase-consumer` crate — the same consumer a third time, with the contract mirror under `src/contract/` and fixtures and schemas copied in by `scripts/sync-assets.mjs`. |
| `docs/` | The VitePress site, part of the deliverable, deployed to Cloudflare Pages. |
| `examples/` | Working scrolls, from `hello-box` (about a minute) to the model demos. |

The public Node surfaces are `scrollcase/contract`, `scrollcase/contract/browser`,
`scrollcase/build`, `scrollcase/consumer` and `scrollcase/sign`, plus the schema and fixture files.
A change to any of them — or to the Python or Rust equivalent — is a change to a public API.

## Data flow

    scroll.json ──▶ pixi solve (pixi.lock) ──▶ conda-pack ──▶ payload ──▶ archive (zip)
                                                   │                        │
                       assets: embedded or deferred ┘                       ▼
                                                    signed release + box.json + licences

A consumer reverses it: verify the signature, check the payload shape, check the archive's size and
hash, check safe entries and manifest agreement — *then* extract, and only then run. Verification
precedes execution, always, in all three consumers.

## External systems

- **conda-forge**, through `pixi`. The only package source.
- **`conda-pack`**, to relocate a solved prefix.
- **Asset hosts** named by the scroll, for deferred assets. Size- and hash-checked before use.
- **An external signer**, optional, dispatched by `src/sign/`. It must echo back the exact payload
  it was given.
- **GitHub Actions** for CI, the demo box builds and the tag-driven releases; **Cloudflare Pages**
  for `scrollcase.dev`, including one Pages Function for Markdown content negotiation.

## Important constraints

- **One contract, multiple implementations.** Python and Rust *mirror* the contract and prove the
  mirror against shared language-neutral fixtures; they never import it and never define the format
  a second time. A change to any consumer's observable behaviour belongs in all three, and in the
  fixture.
- **The schemas are the source of truth for the types.** `src/contract/types/index.d.ts` and every
  `src/**/*.d.mts` are generated by `npm run types`; a test fails when they drift.
- **Determinism and provenance are promises**, each asserted by a test: rebuilding the same commit
  produces a byte-identical archive, and a dirty tree is never quietly recorded as clean.
- **The dependency surface stays small** — `tar`, `yauzl`, `yazl` at runtime, and nothing else.
- **Injection is the test seam**: subprocesses through `run` / `runResult`, network through an
  injectable `fetch`.
- **Four paths break silently** and the single-host suite cannot cover them: the three targets,
  embedded versus deferred assets, local key versus external signer, and toolchain from `PATH`
  versus the project's own. `AGENTS.md` lists them; read a change against each.
